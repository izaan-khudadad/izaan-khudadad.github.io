# Izaan Khudadad — Portfolio

A responsive React portfolio built with Vite. It uses the colorblind-friendly palette shared for the project and includes the graduation photo supplied for the site.

## Run on your computer

1. Install Node.js if it is not already installed.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local address Vite prints.

## Build the site

Run `npm run build`. The finished static site is written to `dist/`.

## Free publishing

This is a static site, so it can be hosted on GitHub Pages for free. Create a GitHub repository for this portfolio, add these files, then use GitHub Pages with GitHub Actions to publish the Vite build. The Vite config uses relative paths so the site also works from a repository subpath. A custom domain is optional.

The project cards link to the corresponding case studies on the existing Wix portfolio. The contact section includes the email and phone number provided for this site. The AI assistant is intentionally left for a separate project.
